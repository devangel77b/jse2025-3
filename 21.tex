Hobby Coach
Many people struggle with finding some sort of passion or hobby that fits for them, but with a simple survey, a website will display the five hobbies best suited for you.

Inspiration
We spend a lot of time on work both in school and out of school, so this project is designed to help people like us find something to enjoy.

What it does
It compares your responses to a dataset, then outputs the top five hobbies for you.

How we built it
We built a website using HTML, CSS, and JS. This was zipped into a file along with a .csv file containing our dataset, which was then uploaded to Replit. From there, the website was up and running.

Challenges we ran into
We had to learn the basics of web development and design in a short time frame.

Accomplishments that we're proud of
Effective creating a usable website with little experience.

What we learned
We learned the basics of web development.

What's next for Hobby Coach
We can try outputting more suited hobbies by sending out surveys, then uploading those responses into a dataset.

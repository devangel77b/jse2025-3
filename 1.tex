Motion
An app to measure various physics concepts in the real world

Inspiration
Growing up we watched our fathers working very hard on certain household projects involving measuring, we felt that there had to be a simpler way to get stuff like that done, and thus we felt the need to make a product capable of making this process simpler.

What it does
The goal is that it is able to measure the distance from point a to point b, and the speed of an object.

How we built it
We originally planned to make it a Kotlin based app, but then decided it would be better as a web app with proper android integration.

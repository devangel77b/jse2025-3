FTC robot turret
The turret will be able to shoot the first tech challenge balls at any angle or in any direction as far as it would need to in a competition

I saw the turrets the other ftc teams used and tried to find a way to make a better one, and I wanted to code it so that it can remember where it is and calculate where it has to shoot instead of the driver doing that. I 3D printed a lot of it but some of it is gobilda parts.

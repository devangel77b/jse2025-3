FastDrop
A more convenient way to share your files across the netwrok

Inspiration
File transfer takes a lot of time. You have to go through thirs parties like Discord or Gmail. We decided to eliminate the fuss

What it does
Allows you to transfer files directly between two computers

How we built it
C++ backend w/ a frontend in React

Challenges we ran into
Connection issues between two devices, sometimes external dependencies conflicted with the minimum required CXX version

Accomplishments that we're proud of
We got the connection working!

What we learned
Managing dependencies is important

What's next for FastDrop
Fixing up backend deployment, properly adding AI overview of files added. Probably some more stuff as well but honestly we don't know.
